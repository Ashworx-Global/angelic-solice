# Project Docs

This folder contains planning and implementation documents.

## Structure

- `features/`: Feature briefs focused on user value and scope.
- `specs/`: Technical specs focused on architecture and delivery details.

## How to use

1. Copy `features/FEATURE_TEMPLATE.md` to a new file like `features/feature-user-onboarding.md`.
2. Flesh out the feature goals and acceptance criteria.
3. Copy `specs/SPEC_TEMPLATE.md` to a new file like `specs/spec-user-onboarding.md`.
4. Link the spec to the feature and define implementation details.

## Suggested workflow

1. Draft feature brief.
2. Review and trim scope.
3. Write technical spec.
4. Build in milestones and keep docs updated as decisions change.
